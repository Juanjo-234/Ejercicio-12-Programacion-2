# Ejercicio-12-Programacion-2
Resolución del ejercicio N°12 de programación 2
El programa muestra como seria el control de envíos de paquetes.
Toma los datos como:
Dirección
Destinatario
Peso del o los paquetes
Cantidad
Con los datos ya obtenidos se calcula el costo total del envío. Para ello se tiene en cuenta la cantidad de paquetes para hacer el calculo del costo final del envío.
